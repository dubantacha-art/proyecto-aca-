## Descripción

Este proyecto consiste en una calculadora desarrollada en Java que permite realizar operaciones matemáticas básicas mediante un menú interactivo en consola.


## Funcionalidades
- Suma de números.
- Resta de números.
- Multiplicación de números.
- División de números.
- Historial de resultados.
- Manejo de excepciones para entradas inválidas.
- Validación de división por cero.

## Clases Utilizadas

### Main
Contiene el menú principal y la interacción con el usuario.

### Calculadora
Contiene los métodos para realizar las operaciones matemáticas.

### DivisionPorCeroException
Excepción personalizada para controlar intentos de división por cero.

## Instrucciones de Ejecución
1. Abrir el proyecto en VS Code.
2. Compilar los archivos Java.
3. Ejecutar la clase Main.
4. Seleccionar una opción del menú.
5. Ingresar los números solicitados.
